# Изгиб тонкой ортотропной пластины — вариант 3

Расчёт изгиба шарнирно опёртой / защемлённой ортотропной пластины методами
Навье, Бубнова–Галёркина и Канторовича–Власова.

## Исходные данные (вариант 3)

| Параметр | Значение |
|---|---|
| a, b, h | 0,75 м; 0,50 м; 0,01 м |
| E₁, E₂ | 1,2·10¹¹ Па; 0,6·10¹¹ Па |
| ν₁, ν₂ | 0,071; 0,036 |
| G̃ | 0,7·10¹⁰ Па |
| q₀ | 10 кПа |

Граничные условия для пункта в): кромки y = 0 и y = b — шарнирное опирание
(обеспечивается множителем sin πy/b, так как вариант нечётный), кромка
x = 0 — жёсткая заделка, кромка x = a — свободный край.

## Сборка и запуск

Никаких внешних библиотек и CMake не требуется — только компилятор C++17.

```bash
make          # или напрямую:  g++ -std=c++17 -O2 main.cpp -o plate
./plate       # или:  make run
```

Время счёта — около 5 с. Все результаты пишутся в каталог `out/`.

```bash
make clean    # удалить бинарник и out/
```

## Два базиса метода Бубнова–Галёркина

1. **Тригонометрический** — φ = sin(mπx/a)·sin(nπy/b). Собственные функции
   оператора задачи, поэтому матрица Галёркина получается диагональной, и
   метод в точности совпадает с методом Навье. Диагональность **не заложена
   в код**: матрица собирается численным интегрированием по общей формуле, а
   отношение max|K_ij, i≠j| / max|K_ii| ≈ 10⁻¹⁵ печатается как результат.

2. **Полиномиальный (балочные функции)** — X_k(ξ) — решение X'''' = ξ^(k−1)
   при X = X'' = 0 на концах, ξ = x/L. Первая из них — классическая
   ξ⁴ − 2ξ³ + ξ. Набор L²-ортонормируется процессом Грама–Шмидта: это не
   меняет натянутое подпространство, но снижает оценку обусловленности
   матрицы с ~10¹⁴ до ~10³.

Отдельно считается «наивный» базис x(a−x)y(b−y), у которого обе четвёртые
производные обращаются в нуль. Из оператора выпадают обе изгибные жёсткости,
и коэффициент разложения оказывается равен q₀/(8δ₁D₁) — вообще не зависящим
от размеров пластины. Это иллюстрация того, зачем базису нужно удовлетворять
и силовым граничным условиям тоже.

## Результаты в ParaView

Файлы `out/*.vtu` — формат XML VTK UnstructuredGrid, ячейки VTK_QUAD.
Точечные поля: `w_mm` (прогиб, мм), `w_m` (прогиб, м), `Mx`, `My`, `Mxy`
(погонные моменты, Н·м/м).

Поверхность прогиба:

1. Открыть `.vtu`, нажать **Apply**.
2. Фильтр **Warp By Scalar**: Scalars = `w_m`, Scale Factor подобрать
   (например 50–100), **Apply**.
3. В Coloring выбрать `w_mm`, нажать **Rescale to Data Range**.
4. Для карт моментов переключить Coloring на `Mx` или `My`.

Сечения: фильтр **Plot Over Line** вдоль x = a/2 или y = b/2. Те же сечения
продублированы в `out/task_*_sections.csv` для построения графиков любым
другим средством.

Таблица сходимости — `out/convergence_A.csv`. Для графика погрешности
удобен логарифмический масштаб по обеим осям: там видна степенная
асимптотика (прогиб и момент сходятся с разной скоростью).

## Смена варианта

Все параметры — поля структуры `Plate` со значениями по умолчанию в
`plate.hpp`. Граничные условия пункта в) задаются аргументами
`solveKantorovich(p, EdgeBC::Clamped, EdgeBC::Free)` в `main.cpp`;
доступны `EdgeBC::Clamped`, `EdgeBC::Simple`, `EdgeBC::Free`.
Для чётных вариантов (нагрузка синусоидальна по x) нужно поменять
местами роли координат в `kantorovich.hpp`.
